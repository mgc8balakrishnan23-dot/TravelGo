# TravelGo – Travel Booking Website

A responsive front-end travel booking demo built with HTML, CSS, Bootstrap and vanilla JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `login.html` in a browser, or use VS Code Live Server.
3. Create an account from **Create account** or sign in with a demo email and a password of at least 4 characters.
4. After sign-in, the home page opens. All internal pages require a signed-in session.

## Features
- Login and registration screens
- Login-first page protection and sign out
- Responsive travel dashboard and navigation
- Destination search and price sorting
- Sample flight and train route search
- Hotel search and price sorting
- Travel packages
- Booking form with traveller details and automatic total calculation
- My Bookings page with booking IDs and cancellation option
- Profile editing
- Browser LocalStorage persistence

## Important demo limitations
This is a front-end academic/demo project. Login and booking data are stored in the browser's LocalStorage; passwords are not securely protected. There is no backend, real inventory, live transport/hotel availability, email confirmation, or payment gateway. Prices and schedules are sample data and no real reservation is created.
